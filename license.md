## 💻 The Matrix Has You

You have seen it in the movies. A hooded figure in a dark room, frantically typing on a keyboard while lines of glowing green code cascade down the screen. It is the ultimate aesthetic of the modern hacker. But the reality of software development is usually a bright white screen and a boring default theme.

**Hacker Terminal Theme** is an open-source collection of meticulously crafted color schemes that transform your development environment into a scene from *The Matrix* or *Mr. Robot*. This is not just a simple color swap. It is a complete visual overhaul.

This repository includes themes for Visual Studio Code, Windows Terminal, iTerm2, and JetBrains IDEs. It features a deep OLED-black background, high-contrast neon green syntax highlighting, and custom file icons that look like they belong in a cyberpunk movie. It also includes a custom font pairing (Fira Code with ligatures) to complete the look. It is the perfect aesthetic for late-night coding sessions.

## ⚙️ Quick Setup

Installing the theme is straightforward. We will use VS Code as an example.

```bash
# Step 1: Clone the repository
git clone https://github.com/your-username/hacker-terminal-theme.git

# Step 2: Copy the theme file to your VS Code extensions folder
cp -r vscode-theme ~/.vscode/extensions/hacker-theme

# Step 3: Open VS Code and select the theme
# Press Ctrl+K Ctrl+T and choose "Hacker Terminal"
```

Once applied, you will notice an immediate change. The background becomes pitch black, the text becomes neon green, and even the scrollbar changes to match the aesthetic.

## 🧠 Under The Hood: The Anatomy Of A Theme

A VS Code theme is not just a list of colors. It is a JSON file (`color-theme.json`) that defines the color for every single UI element.

The file has two main sections: `colors` and `tokenColors`. The `colors` section defines the UI (the sidebar, the status bar, the editor background). The `tokenColors` section defines the syntax highlighting. It uses **TextMate grammars** to identify scopes. For example, a string in Python has the scope `string.quoted.single.python`. Our theme maps that scope to the color `#00FF41`.

We also include a custom **workbench icon theme**. This is a font file where each glyph is a file icon. When you open a `.py` file, VS Code renders the Python icon from our font, giving it a neon glow effect.
